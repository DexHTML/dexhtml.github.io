Server Backups

Server Backups — личное техническое приложение для автоматического резервного копирования данных с серверов владельца в его собственный Google Drive. Оно не предназначено для публичного использования, регистрации других пользователей или продажи услуг.

Для работы приложение использует Google Drive API через OAuth 2.0. Доступ предоставляется только после согласия владельца Google-аккаунта. Приложение может создавать, просматривать, скачивать и управлять файлами резервных копий на Google Диске.

Это информационная страница приложения для настройки Google OAuth. Здесь нет формы входа, доступа к архивам или загрузки секретных данных.

Политика конфиденциальности / Privacy Policy

English summary

Server Backups is a personal, owner-operated utility for backing up data from the owner's servers to the owner's Google Drive account. It uses Google Drive API with OAuth 2.0 authorization. It does not offer accounts or services to the public.
